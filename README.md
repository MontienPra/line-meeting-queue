# LINE Meeting Queue App (ระบบลงคิวประชุมผ่าน LINE LIFF)

ระบบเว็บแอปพลิเคชันสำหรับให้พนักงานลงคิว Meeting กับผู้บริหารหรือหัวหน้างาน (Host) ผ่าน LINE LIFF พร้อมปฏิทินแสดงสถานะสี 4 รูปแบบ การแจ้งสถานที่ประจำวัน (สาขา/WFH) และการควบคุมสิทธิ์อย่างปลอดภัย (พนักงานไม่สามารถแก้ไขคิวของผู้อื่นได้)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. ปฏิทินแสดงสถานะสี 4 รูปแบบ (Calendar 4-Status)
- 🟢 **สีเขียว (ยังไม่ลงคิว / ว่าง)**: วันที่เปิดรับคิวและมีช่วงเวลาว่างพร้อมให้ลงคิว
- 🟡 **สีเหลือง (ลงคิวแล้ว)**: มีพนักงานลงคิวบางช่วงเวลาแล้ว หรือผู้ใช้งานปัจจุบันมีคิวจองในวันนี้
- 🔴 **สีแดง (คิวเต็ม)**: ช่วงเวลาเปิดรับในวันนั้นถูกจองเต็มทั้งหมดแล้ว
- ⚪ **สีเทา (ปิดรับคิว / ลาพักร้อน)**: เจ้าของคิว (Host) ปิดรับคิวตลอดวัน หรือเป็นวันลาพักร้อน/วันหยุด

### 2. การแจ้งสถานที่ประจำวันและสถานะวันลา (Host Duty & Leave)
- แสดงป้ายกำกับใต้ตัวเลขวันที่ เช่น `🏢 สำนักงานใหญ่`, `🏬 สาขาบางนา`, `💻 WFH/ออนไลน์`, `🏖️ ลาพักร้อน`
- เมื่อ Host แจ้งลาพักร้อน วันนั้นจะเปลี่ยนเป็น **สีเทา (⚪ ปิดรับคิว)** ให้อัตโนมัติ
- พนักงานสามารถเลือกได้ว่าจะเข้าพบ ณ สาขา หรือ ประชุมออนไลน์ (Online Call)

### 3. ระบบควบคุมสิทธิ์ที่ปลอดภัย (Strict Access Control)
- พนักงานไม่สามารถแก้ไขหรือยกเลิกคิวของพนักงานคนอื่นได้ (ตรวจสอบอิงตาม LINE User ID)
- พนักงานสามารถยกเลิกได้เฉพาะคิวของตนเองเท่านั้น
- เจ้าของคิว (Host) มีสิทธิ์ตรวจสอบคิวทั้งหมด ยกเลิก หรือบล็อกเวลาได้

### 4. ช่องระบุชื่องาน / หัวข้องาน Event หลากหลาย
- มีช่องกรอก **ชื่องาน / หัวข้อการประชุม (Event Title)**
- มีหมวดหมู่งานให้เลือก เช่น *1-on-1 ปรึกษางาน, ประชุมติดตามงาน (Project Sync), ตรวจแบบและขออนุมัติงาน, นัดคุยงานด่วน, อื่นๆ*
- ช่องบันทึกวาระหรือรายละเอียดเพิ่มเติม

### 5. รองรับทั้ง LINE LIFF จริงและ Dev Test Mode
- สามารถเปิดบนเบราว์เซอร์ปกติและใช้ **Dev Switcher** ที่มุมขวาบน เพื่อสลับบทบาททดสอบได้ทันที:
  - 👑 **เจ้าของคิว (Host / คุณมณเทียร)**
  - 👨‍💻 **พนักงานคนที่ 1: สมชาย ใจดี (ฝ่าย IT)**
  - 👩‍💼 **พนักงานคนที่ 2: สมหญิง รักเรียน (การตลาด)**
- เมื่อใส่ LIFF ID จะเชื่อมต่อกับ LINE App จริงอัตโนมัติ

## 🚀 วิธีการรันใช้งานในเครื่อง (Quick Start)

### 1. ติดตั้ง Dependencies
เปิด Terminal ในโฟลเดอร์โครงการ:
```bash
npm install
```

### 2. รันแอปพลิเคชัน
```bash
npm start
```
แอปจะเปิดทำงานที่: **http://localhost:3000**

## 📱 ขั้นตอนการเชื่อมต่อ LINE LIFF (Live Mode Setup)

หากต้องการนำไปใช้งานจริงบน LINE:

1. เข้าไปที่ [LINE Developers Console](https://developers.line.biz/)
2. สร้าง **Provider** และ **Channel** ประเภท **LINE Login**
3. ไปที่แท็บ **LIFF** แล้วกด **Add**
4. กำหนดค่า:
   - **LIFF app name**: Meeting Queue
   - **Size**: Full (หรือ Tall)
   - **Endpoint URL**: URL ของเว็บแอป (ต้องเป็น HTTPS เช่น URL จาก Vercel, Render หรือ ngrok)
   - **Scopes**: ติ๊ก `profile`, `openid`
   - **Bot link feature**: On (Normal)
5. คัดลอก **LIFF ID** (เช่น `2006789012-ABCdefgh`)
6. เปิดเว็บแอป กดที่รูปโปรไฟล์มุมขวาบน -> เลือก **"ตั้งค่า LINE LIFF ID (Live Mode)"** แล้ววาง LIFF ID ลงไป
7. พนักงานทุกคนจะสามารถกดลิงก์ LIFF (`https://liff.line.me/YOUR_LIFF_ID`) ในแอป LINE เพื่อลงคิวได้ทันทีโดยไม่ต้องล็อกอินใหม่

## 🌐 การ Deploy ขึ้น Cloud (Production Hosting)

เว็บแอปนี้ใช้ Node.js + Express สามารถนำไป Deploy ขึ้นโฮสต์ฟรีได้ง่าย เช่น:

- **Render.com**: เชื่อม Git Repository แล้วเลือก Web Service รันคำสั่ง `npm start`
- **Railway.app**: กด Deploy from GitHub Repository
- **Vercel**: รองรับ Serverless Function หรือรันผ่าน Node.js runtime
